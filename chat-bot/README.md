# chat-bot

Painel Evolution API — React + TypeScript + Tailwind CSS

Painel de controle para gerenciar instâncias WhatsApp via Evolution API, com bots integrados usando Ollama (IA local).

## Funcionalidades

- Gerenciar instâncias WhatsApp (criar, conectar via QR Code, desconectar, excluir)
- Enviar mensagens de teste
- Bots com IA local (Ollama) por instância
- Transcrição de áudio (Whisper)
- Logs em tempo real
- Interface minimalista com tema escuro

## Como rodar

```bash
npm install
npm run dev
```

Acesse http://localhost:5173/
